LE DERNIER CONVOI / CONFIDENTIALITÉ

Ta traversée
reste avec toi.

Le Dernier Convoi est un jeu solo. Il ne demande aucun compte et n’intègre ni publicité, ni analyse de fréquentation, ni achats intégrés.

Application Android

Les cinq régions et le contenu nécessaire au jeu sont inclus dans l’APK 0.2.0. Après installation, une connexion Internet n’est pas nécessaire pour jouer. L’application ne synchronise pas ta campagne avec un serveur.

La sauvegarde de campagne et les préférences sont conservées dans les données locales de l’application. Effacer ces données ou désinstaller le jeu peut supprimer la progression. Les fonctions de sauvegarde ou de transfert du système Android dépendent des réglages de ton appareil.

La reprise d’une sauvegarde 0.1.0 dans la version 0.2.0 se fait localement. Elle ne demande ni compte, ni envoi de ta partie vers un service externe.

Page et démo web

La page et la démo sont hébergées sur GitHub Pages. Le navigateur doit télécharger les fichiers pour les charger. GitHub peut traiter des informations techniques de visite selon sa propre politique de confidentialité ; aucun outil de suivi supplémentaire n’est intégré au projet.

La sauvegarde de la démo utilise le stockage local disponible dans le navigateur. Sa persistance dépend du navigateur, de ses réglages et du mode de navigation. Effacer les données du site peut supprimer la campagne. La sauvegarde web et celle de l’application Android sont indépendantes.

Liens externes

Les liens vers GitHub ouvrent le dépôt, la licence ou les problèmes du projet. Leur utilisation relève du fonctionnement de GitHub. Rien n’est publié dans un dépôt ou dans un problème à partir de ta partie.
