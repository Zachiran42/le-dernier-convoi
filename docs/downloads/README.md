# APK Android

L’APK de développement signé est disponible dans la Release publique :

[Télécharger Le Dernier Convoi 0.2.0](https://github.com/Zachiran42/le-dernier-convoi/releases/download/v0.2.0/le-dernier-convoi-0.2.0.apk)

Android 7.0+ ARM64. Aucune permission Internet. Le jeu et ses ressources sont embarqués. La version publiée utilise une signature de développement stable conservée hors du dépôt.

Cette version contient cinq régions de huit étapes, soit quarante étapes de campagne et cinq gardiens. Les sauvegardes 0.1.0 sont reprises avec leur progression, leurs réserves, leurs modules et leur équipage.

L’empreinte SHA-256 est fournie dans ce dossier et avec la Release.
