# Illustration de couverture

`key-art.png` est l’illustration originale d’ambiance de **Le Dernier Convoi**. Elle est utilisée sur la page publique et peut être utilisée dans les écrans d’ambiance du jeu. Ce visuel est une illustration de couverture, pas une capture du gameplay.

- Création : outil intégré **ImageGen**, le 29 octobre 2026.
- Format livré : PNG opaque, 1672 × 941 pixels.
- Fichier de référence : `art/key-art.png`.
- Copie destinée au site : `docs/assets/key-art.png`.
- Aucune image de référence fournie, aucun logo ni texte incorporé.
- Diffusion avec les créations du projet sous la [licence MIT](../LICENSE).

Le fichier généré a été copié dans le projet sans retouche. Le dessin ne reprend pas un train, un univers ou des personnages d’une franchise particulière.
